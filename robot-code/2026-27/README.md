# AI Future 1 - robot code, BIOGLOW 2026-27 (Pybricks, SPIKE Prime)

Copied 2026-10-29 from the team's working folder (`Team Robot Code/2026-2027 code/AI Future 1`).

| File | What it is |
|---|---|
| `robot.py` | Easy commands for students (`drive`, `turn`, `face`, arm moves) with a cheat sheet at the top |
| `robot_master.py` | The library underneath: gyro-straight driving, PID, arm homing, gear ratios, run logging |
| `run_easy_template.py`, `Run_A.py` ... | A template and the team's mission runs |
| `arm_setup.py`, `arm_check.py` | Measure an arm's range and check its accuracy |
| `tuning-tests/` | The PID / feed-forward tuning experiments behind `robot_master.py` |
| `robot-data/` | Every run is saved as a CSV (`runs/`) and shown on `dashboard.html` (`collect_runs.py` saves them) |

Not copied: students' personal practice files and last season's experiments.
